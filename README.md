# Meteur Online Shopping

Meteur Online Shopping is a modern Kenyan e-commerce marketplace designed to provide customers with a realistic online shopping experience.

## Features

- Modern marketplace homepage
- Original Meteur branding
- Product categories
- Product search
- Product listings
- Flash deals
- New arrivals
- Product ratings
- Shopping cart
- Wishlist
- Customer registration
- Customer login
- Customer dashboard
- Checkout interface
- Order confirmation
- Order tracking
- Delivery information
- Returns and refunds information
- Customer support pages
- Responsive mobile design

## Shopping Categories

- Electronics
- Phones and Tablets
- Fashion
- Shoes
- Beauty
- Home and Appliances
- Computing
- Groceries
- Accessories
- Cameras
- Kitchen
- Smart Devices

## Customer Shopping Flow

Home → Shop → Product Details → Add to Cart → Cart → Checkout → Order Confirmation

## Account Flow

Create Account → Login → Customer Dashboard → Profile → Addresses → Orders → Wishlist

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub
- Vercel

## Project Purpose

This project demonstrates a complete front-end e-commerce marketplace experience for a Kenyan online shopping platform.

## Current Version

The current version is a front-end/static website. Real customer authentication, database storage, M-Pesa payment processing, seller accounts, and other backend services can be connected in a future version.

## Important Notice

Meteur Online Shopping is an independent project using original branding and is not affiliated with Jumia or any other e-commerce company.

Do not use this demonstration website for real payment information, passwords, or other sensitive customer data.
